👩‍🦽 SmileFlow Accessibility

You have reached the CDN for the SmileFlow Accessibility Widget. The files are served live from this subdomain.

Installation

Add the following script tag to the <head> or bottom of the <body> of your website:

<script
  src="https://accessibility.smileflow.ai/smileflow-accessibility.umd.js"
  data-asw-position="bottom-right"
  data-asw-size="58">
</script>

Customization

You can customize the widget by adding data attributes to the script tag:

Attribute Description Options / Example
data-asw-position Corner placement bottom-right, bottom-left, top-right, top-left
data-asw-button-icon Custom button icon URL to image or SVG string
data-asw-size Button size (px) 58
data-asw-offset Corner offset (X,Y) 20,20

Available Files

  • smileflow-accessibility.umd.js (Recommended for script tags)
  • smileflow-accessibility.esm.js (For ESM imports)
  • smileflow-accessibility.cjs.js (For CommonJS)
